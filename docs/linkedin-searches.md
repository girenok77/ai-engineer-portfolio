## Правила перевірки

- Читати повний опис, перевіряти фактичну локацію саме вакансії. Назва країни в меню пошуку, рекомендаціях чи профілі рекрутера не є підтвердженням.
- Remote включати лише з явно вказаною Норвегією; глобальний remote без підтвердження Норвегії не включати.
- Зберігати всі хоча б часткові технічні збіги. Senior, норвезька, cloud, security clearance — прогалини в приватних нотатках, а не автоматичне виключення.
- Закриті й прострочені оголошення зберігати: позначити статус і перевірити актуальне оголошення на сайті компанії перед подачею. Не вигадувати дедлайн.
- ID `linkedin-<числовий job ID>`, URL без tracking-параметрів; перевіряти дублікати тієї ж компанії та посади з NAV/DOU. Повторно не надсилати заявку.
- Публічні LinkedIn-пошуки та вебіндекс не гарантують повного охоплення. При login wall або обмеженні доступу не обходити його й не звітувати про повний перегляд.
- Зберігати записи через agent RPC у приватну чергу. Не подавати форми та не надсилати повідомлення автоматично.
